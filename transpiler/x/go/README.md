## Deprecation notice (MEP-43 Phase 9)

`transpiler/x/go` is the legacy Go transpiler. The MEP-43 successor is
`compiler3/emit/go`, which lowers Mochi through the SSA IR and emits a
typed Go module backed by `runtime/mochi`. The new path is the one
under test by the A/B harness in `compiler3/migrate/ab.go`.

Status of the legacy path:

- Now: kept building so the A/B harness has a reference. Marked
  DEPRECATED here, no API additions accepted.
- Flip date: this directory is deleted in the release immediately after
  `compiler3/migrate.RunBoth` reports byte-for-byte equality on the
  104/105 fixtures below for two consecutive releases.
- Flip gate (MEP-43 Phase 9):
  1. `compiler3/migrate.RunNew` must stop returning `ErrNewPathPending`
     (Mochi-to-IR frontend wiring lands).
  2. `RunBoth` must report `StdoutEqual && ExitEqual` on every entry in
     the checklist for two consecutive releases.
  3. Any divergence is filed as a tracking issue against the new path,
     not the legacy one.

When the flip gate passes, the deletion is mechanical: drop this
directory and remove the `Legacy` runner from `compiler3/migrate`.
