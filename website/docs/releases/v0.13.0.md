# May 2026 (v0.13.0)

v0.13.0 ships the Mochi-to-BEAM/Erlang transpiler (MEP-46), completing
phases 1-18 of the 19-phase delivery plan. You can now compile a Mochi
source file to a self-contained escript that runs on any OTP 27+ node
without a native build step.

```
mochi build --target=beam-escript hello.mochi -o hello
./hello
```

The pipeline runs fully in-process: `parser.Parse` -> `types.Check` ->
`clower.Lower` -> `beamlower.Lower` -> `emit.Emit` -> escript archive.
No `rebar3`, no `mix`, no Makefile.

## 1. BEAM transpiler: MEP-46 phases 1-18

**Hello world through closures (Phases 1-6)**

- Phase 1: escript pipeline from `aotir` through Core Erlang `compile:forms/2`.
  Runtime module `mochi_str.erl` provides UTF-8 `print/1`.
- Phase 1.1: `--target=beam-escript`, `--out PATH`, `--emit=core|erl|beam` CLI flags.
- Phase 1.2: BLAKE3 content-addressed cache under `.mochi/cache/beam/`;
  unchanged source files skip recompilation (copy from cache).
- Phases 2-5: scalars, control flow, records, lists, maps, pattern matching.
- Phase 6.0: anonymous functions and closures via BEAM `c_fun`.
- Phase 6.1: `map(xs, fn)`, `filter(xs, fn)`, `reduce(xs, fn, init)` built-ins
  lower to `lists:map/2`, `lists:filter/2`, `lists:foldl/3`.

**Query DSL and Datalog (Phases 7-8)**

- Phase 7.0: `from x in L where p select e` via BEAM list comprehensions.
- Phase 7.1-7.4: aggregations (`sum`, `max`, `min`), group-by, hash join,
  sort/take/skip.
- Phase 8.0: Datalog engine (`mochi_datalog.erl`) with facts, rules, and queries.
- Phase 8.1: Datalog negation-as-failure (`not alive(X)`).
- Phase 8.2: Multi-free-variable Datalog queries.

**Channels, streams, agents (Phases 9-10)**

- Phase 9.0: `chan<T>` channels backed by BEAM message passing.
- Phase 10.0-10.1: `stream<T>` and `sub<T>` via OTP `pg` process groups.

**Pattern matching and errors (Phases 5, 13.1)**

- Phase 5.0: Sum-type lowering (`{ok,V}` / `{error,E}` tagged tuples).
- Phase 13.1: `panic(code, msg)` raises an Erlang exception; `try/catch`
  catches it via `mochi_raise.erl`.

**LLM generation (Phase 13)**

- Phase 13.0: `generate anthropic { prompt: "..." }` with cassette playback
  for deterministic CI runs.

**HTTP fetch (Phase 14)**

- Phase 14.0+14.1: `fetch URL into var` via OTP `httpc` (inets application)
  with TLS 1.3 verify-peer using system CA bundle (`public_key:cacerts_get/0`).
  No external dependencies.

**Multi-OTP matrix (Phase 16)**

- Phase 16.1-16.2: CI matrix covers OTP 27 stable and OTP 28/29 RC as
  non-blocking nightly jobs.

**Dialyzer cleanliness (Phase 17)**

- Phase 17.0: `-spec` attributes emitted for every exported Mochi function.
- Phase 17.1: `-opaque` attributes for agent/stream reference types.
- Phase 17.2: CI job runs Dialyzer on all runtime `.erl` sources; zero warnings.
- Phase 17.3: `dialyzer_allowlist.txt` documents known false-positive patterns.

**Reproducibility and benchmarks (Phase 18)**

- Phase 18.0: Deterministic `.beam` files (stripped timestamps, sorted defs).
- Phase 18.1-18.2: `TestReproducibility` asserts bit-identical `.beam` bytes
  across two independent builds.
- Phase 18.3: `BenchmarkBeamBuild`, `BenchmarkBeamQuery`, `BenchmarkBeamRun`
  benchmark harness.

**Documentation (Phase 19.0)**

- `docs/manual/build-beam.mdx` covers quick start, OTP version matrix,
  Dialyzer, reproducibility, and benchmarks.

## 2. Notes on deferred phases

The following MEP-46 phases remain deferred pending parser or infrastructure
work:

- Phases 3.3/3.4 (set[T], omap[K,V]), 5.1-5.3 (nested patterns, option[T],
  Result[T,E]), 6.2 (partial application): require new parser syntax.
- Phases 9.1-9.4 (gen_server/spawn), 11.0-11.2 (async/await),
  12.1-12.2 (FFI extern Erlang, Hex.pm deps): require new parser syntax.
- Phases 13.1-13.2 (structured LLM output, live providers),
  14.2 (JSON parse): design work.
- Phase 15.0-15.4 (release packaging via relx/rebar3/mix/AtomVM/Docker):
  infrastructure work.
- Phase 19.2 (Hex.pm publish): external publishing action.
